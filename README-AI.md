# linka — лендинг интеграций

Самостоятельный минималистичный лендинг на React + Vite. Иконки — lucide-react. Не связан с другими проектами.

## Запуск

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

Готовая статика находится в `docs/`. Разместите её на любом статическом хостинге.

Каталог поддерживает поиск, фильтры и окна с описанием. Блок вопросов раскрывается по нажатию. Сервисы приведены как демонстрационные примеры: реального подключения, отправки данных и авторизации нет. Название linka — условный бренд макета. Шрифт Golos Text загружается из Google Fonts; без сети используется Arial.

## Открытие без сервера

После `npm run build` можно открыть `docs/index.html` двойным кликом. JavaScript и CSS встроены в HTML. Папку `documents` нужно сохранять рядом с `index.html`, чтобы работали ссылки на документы. Эта же сборка работает на статическом хостинге, в том числе в подпапке. Без интернета используется запасной системный шрифт.
